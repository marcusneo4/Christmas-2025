CLAW MACHINE IMAGE SETUP
========================

To use the realistic toy background image:

1. Save your claw machine toy image as: claw-machine-toys.jpg
   (or claw-machine-toys.png)

2. Place it in the same folder as index.html

3. If you use a PNG instead of JPG, update styles.css line:
   background-image: url('claw-machine-toys.png');

Alternative: Use an online image
---------------------------------
If you want to use an online image instead:

1. Upload your image to imgur.com or similar
2. Get the direct image link
3. Update styles.css, find:
   background-image: url('claw-machine-toys.jpg');
   
4. Replace with your link:
   background-image: url('YOUR_IMAGE_URL_HERE');

The image should show lots of colorful soft toys/plushies packed together!
